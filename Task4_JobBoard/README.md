🚀 Key Features
Dual-Dashboard System: Separate, customized interfaces for Employers and Job Seekers.

Employer Portal: Fully functional dashboard to post new job listings, manage active roles, and view incoming applications.

Candidate Portal: Interface for job searching, viewing detailed descriptions, and tracking application status.

Authentication: Secure user registration and login to protect sensitive user data.

Resume Handling: Feature for candidates to upload resumes for employer review.

Real-time Database: Integration with MongoDB for persistent data storage of users and jobs.

🛠️ Tech Arsenal
Frontend: React.js for building a dynamic, responsive user interface.

Backend: Node.js and Express.js for handling API requests and server-side logic.

Database: MongoDB (Atlas) for storing job posts, user profiles, and applications.

Styling: Modern CSS3 with a focus on professional layout and glassmorphism elements.

⚙️ How to Run Locally
Clone the repository: git clone https://github.com/yourusername/CODSOFT.git

Setup Backend:

Navigate to /server, run npm install.

Configure your MongoDB URI in a .env file.

Start server with npm run dev.

Setup Frontend:

Navigate to /client, run npm install.

Start the React app with npm start.
